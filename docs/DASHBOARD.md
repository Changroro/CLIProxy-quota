# 대시보드 구현 계약

기존 위젯의 미니멀 디자인을 확장한다. 디자인 모드는 시스템 유지다. 참조는 Refero Acctual 스타일(`11ea61fa-3309-4e35-9f09-caeb97153b36`)의 흰 바탕·일반 글꼴·무채색 표면과 Anthropic Usage 화면(`6532a471-23a5-40d8-b721-0f82ed57c795`)의 기간/계정/모델 필터·입력/출력 분리다. 상태색은 잔여량에만 쓰고, 입력 추이의 파랑과 출력의 회색은 범례로 구분한다.

개발용 pen.dev 문서는 `widget.pen`이다. 선택한 프레임은 빈 화면 `tQMGI`, 예시 라이트 `ou6yt`, 예시 다크 `oSONX`다. 1120px 구성을 기준으로 구현한다. 작은 화면에서는 요약을 두 열로, 그래프를 한 열로 배치하고 계정 표 내부만 가로로 스크롤한다. 웹 추이 패널은 날짜 라벨을 위해 일별 패널보다 약간 넓다. 공개 스크린샷은 가상 데이터를 사용하며 실제 계정과 이력은 포함하지 않는다.

## 조회와 집계

기간은 시작 포함·종료 제외다. 모든 카드·계정 표·그래프에 같은 서비스/계정/모델 조건을 적용하며, SQLite 읽기 트랜잭션 하나로 일관된 결과를 얻는다. 날짜 필터와 일별 집계는 브라우저의 IANA 시간대를 적용한다. 오늘/최근 이틀은 시간별 추이, 더 긴 범위는 일별 추이를 표시한다.

`execution_id`가 중복 제거 키다. 재시도는 별도 실행일 수 있어 인바운드 요청 수와 같다고 단정하지 않는다. 모델은 응답에 보고된 값이 있으면 그 값을 사용하고 없으면 요청 모델을 기록하며 `model_source`로 구분한다.

입력은 캐시를 제외한다. 캐시 읽기·쓰기, 출력은 서로 겹치지 않는다. 추론은 출력에 포함돼 있어 다시 더하지 않는다. `token_breakdown` v2의 미측정·불일치 값은 NULL로 두고 합계에 포함하지 않으며 미측정 요청 수를 표시한다. 실제 청구액이나 과거 이력을 추정하지 않는다.

## 수집과 보안

수집기는 상태 폴더의 OS 파일 잠금으로 중복 실행을 막는다. 정상 주기는 5초, 오류 시 10→20→30초로 늘리고 성공하면 5초로 복귀한다. 파괴적 큐를 읽은 뒤 최소 집계 필드만 임시 저널에 쓰고 SQLite에 반영한다. 재시작 때 저널을 먼저 재생하며 중복은 무시한다. 응답을 받기 전에 연결이 끊기거나 프록시 보관 시간이 지나면 손실 가능성이 있다. 수집 시작·최근 수집·중단 구간을 표시한다.

계정 잔여량은 한 수집기가 120초마다 조회하고 위젯·대시보드에 공유한다. 별칭은 기존 위젯 설정을 읽는다. 제공자 인증 실패·429 캐시·플랜 미확인은 사용량 0으로 바꾸지 않는다.

API는 루프백에만 바인딩한다. 임의 세션 토큰은 로컬 설정 파일과 최초 URL fragment에만 있고, 브라우저는 토큰을 교환한 뒤 URL에서 제거한다. API는 HttpOnly/SameSite 쿠키 또는 로컬 위젯 Bearer를 요구하고, Host·Origin·전용 헤더로 외부 페이지의 요청을 거부한다. 관리 키·OAuth 토큰·API 키·요청 본문은 브라우저나 SQLite로 전달하지 않는다.

`GET /api/accounts`는 캐시, `GET /api/usage`는 집계, `POST /api/session`은 로컬 세션 연결, `POST /api/recording`은 프록시 기록 켜기다. 자동화 CLI `usage`는 같은 Ledger를 호출해 JSON을 출력한다.

## 검증

수집기 중복 방지, 디스크 오류 뒤 저널 재생, 민감 필드 제외, 실행 ID 중복 제거, 필터/합계/그래프 일치, 일별 시간대, 세션/Origin/Host 거부를 테스트한다. 브라우저에서 한·영, 라이트·다크, 360px/1280px, 기간·서비스·계정·모델 필터, 데이터 표, 인증 실패·빈 화면을 확인한다. 운영 큐는 테스트에서 읽지 않고 실제 실행 중인 수집기만 소비한다.
